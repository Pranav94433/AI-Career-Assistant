# AI Career Assistant

An AI-powered career assistant chatbot built with Streamlit and Ollama.

## Features

- Resume upload for PDF, DOCX, and TXT files
- Resume analysis and improvement suggestions
- Career guidance and career-change support
- Interview preparation
- Career roadmaps
- Skill recommendations
- Job search guidance
- LinkedIn advice
- Conversation memory
- Responsive design for desktop, tablets, and mobile
- User ratings and feedback
- Email notifications for feedback

## Technologies

- Python
- Streamlit
- Ollama
- Llama 3.2
- Scikit-learn
- PyPDF
- Python-docx
- SMTP
